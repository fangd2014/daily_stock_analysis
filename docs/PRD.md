# PRD - 股票智能分析系统产品需求文档

## 1. 产品概述

### 1.1 产品背景

随着A股/港股/美股市场的日益复杂，个人投资者需要一个智能化的股票分析工具来辅助投资决策。本系统基于AI大模型，为投资者提供每日的股票分析报告和决策建议。

### 1.2 产品定位

**目标用户**: A股/港股/美股的个人投资者

**核心价值**: 每日自动分析自选股，生成「决策仪表盘」，包含买卖点位、风险提示、操作检查清单

**差异化优势**:
- 多数据源自动故障切换，确保数据可用性
- 内置交易纪律（严禁追高、趋势交易、精确点位）
- 多渠道实时推送（企业微信、飞书、Telegram、邮件等）
- 支持GitHub Actions零成本部署

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| 决策仪表盘 | 系统输出的核心分析报告，包含买卖建议和操作清单 |
| 乖离率 | (当前价格 - 均线) / 均线 * 100%，用于判断价格偏离程度 |
| 多头排列 | MA5 > MA10 > MA20，表示上涨趋势 |
| 狙击点位 | 系统计算的精确买入/卖出价格 |
| 熔断器 | 防止API过载的自动保护机制 |

## 7. 优先级定义

### P0 - 阻断级

- 多数据源接入和故障切换
- 技术指标计算
- 核心买卖建议生成
- 风险预警（乖离率检测）
- 至少一个通知渠道

### P1 - 重要级

- 舆情分析
- 大盘复盘
- 多渠道推送
- Web管理界面

### P2 - 增强级

- 高级技术指标（MACD、KDJ等）
- 筹码分布
- 历史数据查询
- 任务队列优化
